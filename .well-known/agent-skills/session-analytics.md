# Session Analytics Skill

Extract structured intelligence, attendee interactions, and conversion outcomes from Seminara sessions.

## When to Use This Skill
- Pulling attendee engagement duration and per-slide drop-off statistics.
- Exporting full Q&A transcripts and AI response fidelity logs.
- Syncing collected lead capture contacts directly into CRM pipelines.

## API Endpoint
`GET https://seminara.online/api/v1/agent/sessions/{id}/leads`
